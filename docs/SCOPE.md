# Alcance del MVP de investigación

## Núcleo

1. Inventario y línea base reproducible de PyroPrev.
2. Corpus sintético positivo, benigno e histórico.
3. Hook local de pre-commit.
4. Escaneo del árbol actual y del historial Git.
5. Workflow reutilizable de GitHub Actions.
6. Configuración cifrada con SOPS.
7. Federación OIDC GitHub-Azure.
8. Infraestructura mínima declarada con Bicep.
9. Honeytoken, alerta y playbook de respuesta.
10. Experimentos de detección, latencia, respuesta y adopción.
11. Guía de integración para equipos académicos.
12. Kit de inicio seguro, basado en `azd` y Bicep, para instalar y operar el perfil validado del framework.

## Exclusiones

- Alta disponibilidad productiva.
- Multi-cloud.
- Pruebas de carga masiva.
- Ataques contra sistemas externos.
- Reconstrucción completa de PyroPrev.
- Herramientas pagadas.
- Uso compartido de identidades o beneficios estudiantiles.
- Configurador universal de Azure, interfaz gráfica o catálogo amplio de servicios.
- Garantía permanente de costo cero sin validar oferta, cuota, región y fecha.

## Regla de incorporación

Una tarea nueva solo ingresa al núcleo si responde una pregunta de investigación o reemplaza una tarea de esfuerzo equivalente. Las demás ideas se documentan como extensiones o trabajo futuro.
